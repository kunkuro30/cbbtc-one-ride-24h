One-ride cbBTC trend bot: catch the day's first real 30-minute up-move, ride it with a 2% trailing stop, never churn. Dev window: net PnL +$31.83 on $1,000 paper, 1 trade, max drawdown 2.06%.

## Run it

```sh
node main.ts
```

The bot speaks agent-fun/bars-replay/v1 on stdin/stdout (hello, one batch per minute, done). Standard library only; `vendor/makefun-bars.ts` is the kit's TypeScript shim, copied byte for byte.
